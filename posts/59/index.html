    Spring Cloud Alibaba 2021.0.1.0 踩坑记录

    September 4, 2022 · 7 min
    我打算把**Spring Cloud Alibaba**升级个版本，看看有什么新特性，结果升级后死活启动不了。

    事情是这样的，跟往常一样，我先去Spring官网找到Spring Cloud Alibaba的最新的版本号，如下图所示：

    可以看到最新的版本是2021.0.1.0

    我默默记下这个版本号… 然后点了右上角的那只章鱼猫 在Wiki里找到版本说明，如下图所示： 现在我知道了Spring Cloud Alibaba Version、Spring Cloud Version和Spring Boot Version三者版本对应关系了！

    我再次回到Spring官网，然后打开Spring Cloud Alibaba的Reference，根据文档，一顿操作。 其实大概就只有三步：

    1. 添加依赖
    <!--在父工程添加以下依赖-->
<properties>
        <spring.cloud.version>2021.0.1</spring.cloud.version>
        <spring-boot-dependencies.version>2.6.3</spring-boot-dependencies.version>
        <com.alibaba.cloud.spring-cloud-alibaba-dependencies.version>2021.0.1.0
        </com.alibaba.cloud.spring-cloud-alibaba-dependencies.version>
</properties>
<dependencyManagement>
        <dependencies>
            <!--官网里使用spring-boot-starter-parent作为父工程而没有导入这条依赖，实际作用相同-->
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-dependencies</artifactId>
                <version>${spring-boot-dependencies.version}</version>
            </dependency>
            <dependency>
                <groupId>org.springframework.cloud</groupId>
                <artifactId>spring-cloud-dependencies</artifactId>
                <version>${spring.cloud.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
            <dependency>
                <groupId>com.alibaba.cloud</groupId>
                <artifactId>spring-cloud-alibaba-dependencies</artifactId>
                <version>${com.alibaba.cloud.spring-cloud-alibaba-dependencies.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
        </dependencies>
</dependencyManagement>

    <!--在module中添加以下依赖-->
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
</dependency>
    1. 配置yaml
    spring:
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848
    1. 在主类上添加**@EnableDiscoveryClient**注解 激动的心，颤抖的手，点击运行！（提前启动好了Nacos）

    报错提示ClassNotFoundException，很明显，这种问题一般都是出现在缺少依赖的情况下的，但是jackson这个东西，我之前一直用的好好的啊！怎么突然就说找不到了呢？ 我在密密麻麻的POM文件中看了半天，也没发现什么问题。我也没做多大改动啊，怎么就跑不起来了呢？ 我想了下，问题会不会是依赖冲突导致的？ 我去看看External Libraries：

    卧槽，怎么会有两个jackson-core?版本还不一致！ 终于找到原因了！ 接下来，我修改了nacos的依赖：

    <dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
    <!--排除此依赖对jackson-core的依赖-->
    <exclusions>
        <exclusion>
            <groupId>com.fasterxml.jackson.core</groupId>
            <artifactId>jackson-core</artifactId>
        </exclusion>
    </exclusions>
</dependency>

    改完后External Libraries里就只剩下一个jackson-core-2.13.1了 刷新一下Maven，再次运行，终于Run起来了！
