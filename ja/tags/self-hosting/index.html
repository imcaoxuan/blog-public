Send Codex CLI Notifications to iPhone and Apple Watch with ntfy

私は自ホストの ntfy サーバーを利用して、Codex CLI の完了通知を iPhone と Apple Watch に送信しています。メッセージにはプロジェクトディレクトリ名と短い状態が含まれます。承認のプロンプトを表示すると、macOS Terminal のターミナルベルが鳴ります。 プライベートトピックを準備する ntfy サーバーに通常のユーザーを作成し、codex トピックへのアクセス権を追加します。Docker で展開している場合は、ntfy コンテナ内で次のコマンドを実行してください。 ntfy user add codex ntfy access codex codex rw ntfy token add --label="Codex CLI" codex この例では、認証が有効で、匿名ユーザーにはそのトピックへのアクセス権がないことを前提としています。ntfy iOS アプリに自ホストのサーバーを追加し、ユーザー名とパスワードを使用して codex を購読します。生成された tk_… トークンは、CLI からメッセージを公開するために保管してください。この例では、同じアカウントでメッセージを公開して購読できます。ntfy のアクセス制御ドキュメントを参照してください。 iOS のバックグラウンド配信を有効にする 次のキーを現在使用中のサーバー設定に統合し、ntfy を再起動します。アプリ内のスキーム、ホスト名、ポートは base-url の設定と一致させる必要があります。 base-url: "https://ntfy.example.com" upstream-base-url: "https://ntfy.sh" 自ホストの通知では、上流へのリクエストにメッセージ ID と完全なトピック URL の SHA-256 ハッシュ値が含まれます。上流サービスでは、サーバーの送信元 IP とリクエストのタイミングも観測できます。Firebase と APNs がWake 信号を中継します。その後、iPhone は自ホストのサーバーから通知本文を取得するため、外出先でもサーバーにアクセスできる必要があります。たとえば VPN を使用してください。ntfy の iOS 配信ドキュメントを参照してください。 通知スクリプトをインストールする Codex を実行するユーザーアカウントの ~/.codex/codex-notify.sh として保存します。サンプルのトピック URL を置き換えてください。jq をインストールすると、通知にプロジェクト名を含められます。インストールしない場合は、完了状態だけが通知に含まれます。 ...
